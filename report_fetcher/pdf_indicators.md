# 从 PDF 报告需抓取的看板指标（对照 PPT「同行业对比」）

根据《A股上市公司2021年-2025年同行业对比》PPT，看板需要以下数据，需从巨潮下载的定期报告 PDF 中解析。

## 解析策略（工程根目录 `annual_report_parser.py`）

- **一套主正则**：营业收入、归母净利润、扣非净利润、经营现金流、总资产、净资产、ROE（加权）等，统一用正则从「主要会计数据和财务指标」区抓**第一个数字**（当年列）。
- **上交所/深交所兼容**：深交所模板指标名后带「（元）」或「（%）」，正则以 `(?:（元）)?` 等形式兼容，上交所无括号同样匹配。
- **调整后分支**：若正文出现「调整前」「调整后」，则走表格解析，定位「调整后」列并取该列数值（如青木科技）；否则走主正则。
- **公司归类**：凯淳/壹网壹创/若羽臣/丽人丽妆 → 主正则；青木 → 表格+调整后列。

## 指标清单（中文表头 → 我们 JSON 字段名）

| PPT/看板用途           | 报告表常见列名（可能略有差异）     | 我们字段名               | 单位/说明        |
|------------------------|-------------------------------------|--------------------------|------------------|
| 营业收入趋势           | 营业收入、营业总收入                 | revenue                  | 元，存为数字     |
| 净利润趋势             | 净利润、归属于母公司净利润         | net_profit               | 元，存为数字     |
| 净利润（扣非）         | 扣非净利润、扣除非经常性损益后净利润 | net_profit_deducted      | 元，存为数字     |
| 毛利率分析             | 毛利率、销售毛利率                   | gross_margin_pct         | %，0–100         |
| 盈利能力（净利率）     | 净利率、销售净利率                   | net_margin_pct           | %，0–100         |
| 盈利能力（ROE）        | 净资产收益率、ROE                    | roe_pct                  | %，0–100         |
| 资产负债率             | 资产负债率                           | debt_ratio_pct           | %，0–100         |
| 资产周转率             | 总资产周转率、资产周转率             | asset_turnover           | 次数，小数       |
| 总资产/资产规模        | 总资产、资产总计                     | total_assets             | 元，存为数字     |
| 经营现金流             | 经营活动产生的现金流量净额           | operating_cash_flow      | 元，存为数字     |
| 现金及等价物           | 现金及现金等价物余额、货币资金       | cash_and_equivalents     | 元，存为数字     |

以上字段在 `data/financials.json` 的每条 `records` 中保存；若某报告未解析到则对应为 `null`。
